\# MintoAI Rigger



An open-source research project for AI-assisted Live2D rigging through supervised learning and procedural geometry generation.



\## Objectives



\- Learn mesh deformation from authorized Live2D models.

\- Generate rigging parameters for new characters.

\- Reduce manual rigging workload.

\- Support local GPU training.

\- Maintain transparent and reproducible research.



\## Technology



\- Python

\- PyTorch

\- CUDA

\- JavaScript

\- Neural Networks

\- Computational Geometry

\## Data and Copyright



Training data must be explicitly authorized for AI training.



Original character assets, extracted training datasets, third-party SDKs and model weights are excluded from this repository unless separate distribution permission is granted.



\## Disclaimer



This is an experimental research project. Production-quality automatic rigging has not yet been achieved.



MintoAI is not affiliated with Live2D Inc.
